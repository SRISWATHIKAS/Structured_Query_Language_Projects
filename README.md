# Structured_Query_Language_Projects
Developed a SQL database project to manage and analyze data using queries, joins, filtering, and aggregation.


## 📌 Overview

This repository contains a collection of SQL database projects created to practice database design, data management, and SQL querying using MySQL.

## 📂 Projects Included

### 1. 🎬 Movies Database

* Created a movies database with movie `name`, `release year`, `actor`, `language`, and `director` details.
* Practiced data insertion, filtering, sorting, joins, and aggregate functions.
* Included a normalized movie database using master tables and foreign key relationships.

### 2. 👨‍💼 Employee Database

* Created an employee database containing employee details such as name, department, salary, gender, joining date, and experience.
* Practiced `SELECT`, `WHERE`, `ORDER BY`, `DISTINCT`, `LIKE`, and aggregate functions.
* Performed employee data filtering and analysis.

### 3. 🎓 Student Career Database

* Created a student career database containing `education`, `skills`, `internships`, `interests`, `job goals`, and `placement status`.
* Practiced SQL queries to analyze student qualifications, skills, career preferences, and placement details.

### 4. 🏥 Hospital Database

* Created a hospital patient records database.
* Stored patient details, `diseases`, `health information`, `treatment costs`, and `admission/discharge dates`.
* Practiced queries for patient data retrieval, filtering, and analysis.

### 5. 🍔 Swiggy Database

* Designed a food delivery database with `customers`, `restaurants`, `menu items`, `orders`, `delivery partners`, `payments`, and `reviews`.
* Established relationships using primary keys and foreign keys.
* Practiced relational database design and SQL data management.

### 6. 🏦 Banking Database

* Created a banking database with customer account details and account balances.
* Implemented a stored procedure for depositing money.
* Implemented a stored function to retrieve account balances.
* Practiced the difference between procedures and functions.

### 7. ⚡ SQL Trigger Database

* Practiced SQL triggers to automate actions when database events occur.
* Covered database operations such as `INSERT`, `UPDATE`, and `DELETE`.
